# Проект автоматизации тестирования API

Этот репозиторий содержит автоматизированные тесты для REST API, написанные на Python. Проект демонстрирует полный цикл работы с API-тестами: от написания кода до автоматического запуска в CI/CD и генерации подробных отчетов.

## Стек технологий

*   **Язык программирования:** Python 3.10
*   **Тестовый фреймворк:** Pytest
*   **HTTP-клиент:** Requests
*   **Валидация данных:** Pydantic
*   **Система отчетов:** Allure
*   **Параллельный запуск:** pytest-xdist
*   **Работа с переменными окружения:** python-dotenv
*   **CI/CD:** GitHub Actions

## Начало работы

### Предварительные требования

*   Установленный Python (версия 3.10 или выше)
*   Установленный Allure Commandline

### Установка

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL вашего репозитория>
    cd <название папки проекта>
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    # Для Windows
    python -m venv venv
    .\venv\Scripts\activate

    # Для macOS/Linux
    python3 -m venv venv
    source venv/bin/activate
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Создайте файл переменных окружения:**
    В корне проекта создайте файл с именем `.env` и добавьте в него базовый URL вашего API:
    ```
    BASE_URL=http://localhost:8080
    ```

## Запуск тестов

### Локальный запуск

*   **Для последовательного запуска тестов:**
    ```bash
    pytest
    ```

*   **Для параллельного запуска тестов (быстрее):**
    ```bash
    pytest -n auto
    ```

### Генерация Allure-отчета

1.  **Запустите тесты, сохранив результаты для Allure:**
    ```bash
    pytest --alluredir=allure-results
    ```

2.  **Сгенерируйте и откройте HTML-отчет:**
    ```bash
    allure serve allure-results
    ```
    В вашем браузере откроется страница с подробным отчетом о прохождении тестов.

## CI/CD

Проект настроен для автоматического запуска тестов с помощью **GitHub Actions**. Пайплайн запускается при каждом `push` или `pull request` в ветку `main`.

**Процесс CI/CD включает в себя:**
1.  Установку зависимостей.
2.  Запуск тестов.
3.  Генерацию Allure-отчета.
4.  Публикацию отчета на **GitHub Pages**, делая его доступным по постоянной ссылке.
